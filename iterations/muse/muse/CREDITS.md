## Separate iterations and evidence

Codex 0.2.0, Claude's courier with pinned 0.1.0 broker core, and Muse's 0.2.0
candidate remain independent snapshots and runtimes. Red did not author every
inherited core file. Nua did not author every host-adapter or configurable
derivative file. Lily's design/editorial review is distinct from executed tests.

Historical source manifests and validation receipts describe their original
snapshots. Collection 0.2.1 adds license, credit and packaging metadata without
changing executable code or tests. New distribution manifests describe the
newly packaged bytes. The frozen 0.2.0 release remains available unchanged.

The public record includes original documentation and summarized observations,
not private conversations, game logs, player files or credentials.
